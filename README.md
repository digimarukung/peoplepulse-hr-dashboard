# PeoplePulse — HR analytics dashboard demo

ตัวอย่างแดชบอร์ดรายงานบุคลากรสำหรับใส่ใน portfolio สร้างด้วย TypeScript และ Vite โดยใช้ข้อมูลสมมติทั้งหมด ไม่มีข้อมูลพนักงานหรือลูกค้าจริง และยังไม่ได้เชื่อมต่อ API หรือระบบ HR

## ตัวอย่างนี้แสดง

- KPI ภาพรวมกำลังคน การเข้าใหม่ และอัตราการลาออก
- กราฟแนวโน้มเข้าใหม่/ลาออกแบบ SVG
- สรุปจำนวนพนักงานตามแผนกและสถานะกำลังคน
- ตารางกิจกรรมพร้อมข้อมูลจำลอง
- เลือกปีเพื่อปรับชุดข้อมูลตัวอย่าง และรองรับหน้าจอมือถือ

## เริ่มใช้งานในเครื่อง

```sh
npm install
npm run dev
```

## สร้างไฟล์สำหรับเผยแพร่

```sh
npm run build
```

เผยแพร่ได้ด้วย GitHub Pages ผ่าน workflow ใน `.github/workflows/deploy.yml` โดยตั้งค่า repository ให้ใช้ GitHub Actions เป็น Pages source

## Portfolio note

นี่คือ **demo project** ที่จัดทำเพื่อแสดงแนวทางออกแบบ dashboard และการพัฒนา frontend ไม่ใช่ผลงานจากลูกค้าหรือระบบที่นำไปใช้งานจริง
